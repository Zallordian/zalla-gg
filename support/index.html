  • Zalla version (Settings → About in the app, or the App Store / TestFlight build number)

Common fixes

Page will not load

Check network, try Reload, or open the same URL in another browser to see if the site is down.

Clear browsing data

Settings → Privacy → Clear browsing data. This closes all tabs and removes history, cookies, website caches, and saved page zoom levels. Bookmarks and downloads are kept.

Burn It All

Find it in the Menu, in Tabs, or add it to your Quick Action buttons in Settings. Zalla asks you to confirm, plays a fire effect, then erases your tabs, history, cookies, and site data and opens a fresh tab. Bookmarks, downloads, and settings stay. The app does not quit. If you would rather skip the fire, turn off Burn It All fire effect in Settings → Privacy and you get a quick fade instead.

Reset preferences

Settings → Privacy → Reset the App restores settings and home shortcuts to their defaults and clears downloads. Bookmarks are kept.

Restore Purchases

If Zalla Unlock is not showing as unlocked, for example after reinstalling or moving to a new iPhone, open Settings → Premium → Zalla Unlock and tap Restore Purchases. Make sure you are signed in to the same Apple Account you bought it with. Apple handles the purchase, so Zalla cannot look it up for you. If it still does not restore, email us.

Import bookmarks

Use an HTML bookmark export from Safari, Chrome, or Firefox, then import from Settings → Browsing, Library → Bookmarks, or onboarding.

Export As / Photos

Long-press an image, choose Export image as, then Save to Photos if you want it in your library. iOS must allow Photos access.

Reader mode

Menu → Reader mode. Some pages do not extract cleanly; Exit reader and browse normally.

Private tabs

Use New Private Tab from the tab menu. Private browsing still loads live websites; sites can still see that visit.

Feedback and TestFlight

Bug reports and feature ideas are welcome at the same email. If you are on TestFlight, include the build number shown in TestFlight.
