Get help

Email ZallaBrowser@pm.me with:

  • What you were trying to do
  • What happened instead
  • Your iPhone model and iOS version (Settings → General → About)
  • Zalla version (Settings in the app, or the App Store / TestFlight build number)

We read every message. Replies may take a day or two.

Common fixes

Page will not load. Check network, try Reload, or open the same URL in another browser to see if the site is down.

Clear browsing data. Settings → Clear browsing data. This clears history, website data, and tabs as described in the app. Downloads may be kept.

Reset preferences. Settings → Reset the App restores default home shortcuts and related prefs. Bookmarks are kept.

Import bookmarks. Use an HTML bookmark export from Safari, Chrome, or Firefox, then import from Library or onboarding.

Export As / Photos. Long-press an image, choose Export image as, then Save to Photos if you want it in your library. iOS must allow Photos access.

Reader mode. Menu → Reader mode. Some pages do not extract cleanly; Exit reader and browse normally.

Private tabs. Use New Private Tab from the tab menu. Private browsing still loads live websites; sites can still see that visit.

Feedback and TestFlight

Bug reports and feature ideas are welcome at the same email. If you are on TestFlight, include the build number shown in TestFlight.
